# TODO App (Frontend Only)

This is a simple TODO application frontend that allows users to add, edit, delete, and mark tasks as completed. This project includes only the frontend part and does not include the backend/server functionality.

## Features

- Add new tasks by typing in the input box and clicking the "Add" button.
- Edit existing tasks by clicking the pencil icon next to each task.
- Delete tasks by clicking the trash icon next to each task.
- Mark tasks as completed by clicking on the task text (toggles line-through style).

## How to Use

1. Open the `index.html` file in any modern web browser.
2. Type your task in the input box.
3. Click the "Add" button to add the task to the list.
4. To edit a task, click the pencil icon next to it, modify the      text, and click outside the input box to save.
5. To delete a task, click the trash icon next to it.
6. Click on a task to toggle its completion status (line-through).

## Technologies Used

- HTML
- CSS
- JavaScript
- [FontAwesome](https://fontawesome.com/) for icons

## Notes

- This project does not include backend functionality. All tasks are managed on the client side and will not persist after refreshing the page.
- To add backend support, a server and database would be required.
